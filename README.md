# ربات خبریوم | Khabarioom

ربات گردآوری خبر برای کانال تلگرام [@khabarioom](https://t.me/khabarioom).

## قابلیت‌های فعلی
- دریافت خبر از منابع RSS، صفحات وب و کانال‌های عمومی تلگرام که در `sources.yaml` تنظیم شده‌اند.
- بررسی منابع هر ۳۰ دقیقه (قابل تنظیم با `FETCH_INTERVAL_MINUTES`).
- جلوگیری از انتشار دوبارهٔ URLهایی که قبلاً با موفقیت منتشر شده‌اند.
- تلاش برای استخراج تصویر و متن خبر.
- درج دو هشتگ و امضای `@khabarioom`.
- دستورات مدیریتی `/status`، `/sources` و `/search کلمه`.
- ساعات سکوت ۰۱:۰۰ تا ۰۷:۰۰ به وقت تهران برای خبرهای غیر اولویت‌دار؛ تشخیص خبر اولویت‌دار فعلاً بر اساس کلیدواژه است و راستی‌آزمایی مستقل نیست.
- پشتیبانی از Docker و Railway.

## اجرای محلی
نیازمند Python 3.12 یا جدیدتر:

```powershell
py -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
Copy-Item .env.example .env
# فایل .env را باز کنید و توکن ربات و آیدی عددی مدیر را وارد کنید.
python main.py
```

در Linux/macOS از `source .venv/bin/activate` استفاده کنید.

## گزارش‌های روزانه\n- آب‌وهوای تهران: هر روز ساعت ۰۷:۱۵ به وقت تهران.\n- بازار: هر روز ساعت ۰۸:۰۰؛ قیمت‌های دلار، طلای ۱۸ عیار، بیت‌کوین، سکه و آب‌شده از API ارزهام نیاز به `ARZHAAM_API_KEY` دارد؛ قیمت نفت WTI از Yahoo Finance دریافت می‌شود. بدون کلید، قیمت‌های محلی به‌صورت «در دسترس نیست» نمایش داده می‌شوند.\n- اندیشهٔ روز: هر روز ساعت ۰۹:۰۰؛ متن‌ها برداشت آزاد هستند و به‌عنوان نقل‌قول مستقیم افراد معرفی نمی‌شوند.\n\n## متغیرهای ضروری
- `TELEGRAM_BOT_TOKEN`: توکن BotFather؛ فقط در محیط اجرا نگه‌داری شود و هرگز در Git ثبت نشود.
- `CHANNEL_ID`: پیش‌فرض `@khabarioom`.
- `ADMIN_USER_IDS`: آیدی عددی حساب مدیر، برای دستورات مدیریتی.
- `DATABASE_PATH`: مسیر دیتابیس SQLite. در میزبانی ابری برای حفظ داده‌ها Volume پایدار تنظیم کنید.

تنظیمات کامل در `.env.example` آمده است. مقدار `ADD_SOURCE_LINK=false` باعث می‌شود لینک منبع در پست عمومی درج نشود؛ اطلاعات منبع در دیتابیس برای بررسی داخلی نگه داشته می‌شود.

## استقرار با Docker/Railway
از این ریپو Deploy کنید و متغیرهای لازم را در بخش Variables/Environment تنظیم کنید. برای SQLite یک Volume پایدار متصل کنید. توکن را داخل فایل‌های ریپو ننویسید.

## نکتهٔ مهم دربارهٔ متن خبر
تنظیم پیش‌فرض کپی کامل خبر خاموش است. خروجی فعلی هنوز سامانهٔ هوش مصنوعی برای بازنویسی و راستی‌آزمایی چندمنبعی ندارد؛ قبل از انتشار عمومی پایدار باید این بخش و صحت تک‌تک RSSها آزموده شوند. تصاویر و متن ممکن است به دلیل محدودیت یا تغییر ساختار سایت در دسترس نباشند.
